PassPony 是一款为想要掌控自己密码的人打造的密码管理器。每个条目都是你所控制的密码库中的一个加密文件，格式与 pass 和 passage 命令行工具相同。你的 Mac、你的服务器和你的手机都可以使用同一个密码库。

为什么选择基于文件的密码库
一个条目，一个文件：第一行是密码，其后可以写任何其他内容。
用你的密钥加密：passage 密码库使用 age 身份，pass 密码库使用 OpenPGP 密钥。
通过 HTTPS 或 SSH 使用 git 同步：克隆你现有的密码库或发布一个新的密码库，并按条目解决冲突，绝不静默合并。
互通：提交与 pass CLI 的格式一致，因此密码库在桌面工具中依然完全可用。

日常使用
自动填充：登录时，你的密码会出现在键盘上方。只有条目名称会被索引；在你填充之前不会解密任何内容。
通行密钥：为网站保存通行密钥，并用它登录。通行密钥存放在该网站的条目中，用你的密钥加密，并像其他内容一样同步。
一次性验证码：带倒计时圆环的 TOTP、HOTP 计数器，并可从 Google Authenticator 导出数据中导入。
使用面容 ID 或触控 ID 解锁，五分钟宽限期与自动填充共享。
临时剪贴板：复制的内容仅保存在本机，并在 45 秒后清除。
字段级编辑，未改动的行会原样保留每一个字节。

你的密钥始终属于你
将手机上的所有密钥备份到一个用恢复码锁定的文件中，并在新手机上恢复。
SSH 同步使用在手机上生成或导入的密钥；主机在首次使用时即被信任，主机密钥发生变化时会被拒绝。
共享同一个密码库的每部手机会在同步时将自己的公钥添加进去，在你的条目为某个新密钥重新加密之前，每个新密钥都需要你批准。私钥绝不会离开设备。

架构层面的隐私保护
无需账户，无需注册，也没有 PassPony 服务器。唯一的网络连接就是你配置的 git 远程仓库。
无分析，无广告，无跟踪。
开源，采用 Apache-2.0 许可证。完整的应用及其 Rust 核心均发布在公开的 git 仓库中，任何人都可以审查。

格式
passage 密码库使用现代的 age 身份加密。
pass 密码库使用 OpenPGP 密钥加密（软件支持 Cv25519 和 X25519/Ed25519）。使用 RSA 密钥的密码库需要智能卡，目前尚不支持。
每种格式各自使用独立的密码库；切换格式绝不会影响另一种。

已提供英语、西班牙语、法语、德语、简体中文、巴西葡萄牙语和俄语版本。

如果你已经在使用 pass 或 passage，PassPony 正是你这套方案中缺失的手机端。如果你从未用过它们，首次运行的导览会带你在大约一分钟内添加第一个密码。
