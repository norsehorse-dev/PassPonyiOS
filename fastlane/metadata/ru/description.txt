Менеджер паролей PassPony создан для тех, кто хочет сам владеть своими паролями. Каждая запись хранится в отдельном зашифрованном файле в хранилище, которое вы контролируете, в том же формате, что и у утилит командной строки pass и passage. Ваш Mac, ваш сервер и ваш телефон могут работать с одним и тем же хранилищем.

ПОЧЕМУ ХРАНИЛИЩЕ НА ФАЙЛАХ
Одна запись, один файл: пароль в первой строке, всё остальное после него.
Шифрование вашими ключами: идентификаторы age для хранилищ passage, ключи OpenPGP для хранилищ pass.
Синхронизация через git по HTTPS или SSH: клонируйте существующее хранилище, опубликуйте новое и разрешайте конфликты для каждой записи отдельно, без незаметного автоматического слияния.
Совместимость: коммиты соответствуют формату CLI pass, поэтому хранилищем можно полноценно пользоваться и из настольных утилит.

ПОВСЕДНЕВНОЕ ИСПОЛЬЗОВАНИЕ
Автозаполнение: пароли появляются над клавиатурой, когда вы входите в аккаунт. Индексируются только названия записей; ничего не расшифровывается, пока вы не выберете запись для заполнения.
Ключи доступа: сохраните ключ доступа для сайта и входите с его помощью. Он хранится в записи этого сайта, зашифрован вашими ключами и синхронизируется, как и всё остальное.
Одноразовые коды: TOTP с кольцом обратного отсчёта, счётчики HOTP и импорт из QR-кодов экспорта приложения-аутентификатора.
Разблокировка с помощью Face ID или Touch ID и пятиминутный льготный период, общий с автозаполнением.
Временный буфер обмена: скопированное остаётся только на устройстве и очищается через 45 секунд.
Редактирование отдельных полей, при котором строки, которые вы не трогаете, сохраняются байт в байт.

ВАШИ КЛЮЧИ ОСТАЮТСЯ ВАШИМИ
Создайте резервную копию всех ключей с телефона в одном файле, защищённом кодом восстановления, и восстановите её на новом телефоне.
Для синхронизации по SSH используется ключ, созданный на телефоне или импортированный; при первом подключении хост добавляется в доверенные, а изменённый ключ хоста отклоняется.
Каждый телефон, работающий с общим хранилищем, при синхронизации добавляет в него свой открытый ключ, и вы подтверждаете каждый новый ключ, прежде чем для него будут перешифрованы ваши записи. Секретные ключи никогда не покидают устройство.

КОНФИДЕНЦИАЛЬНОСТЬ НА УРОВНЕ АРХИТЕКТУРЫ
Ни аккаунта, ни регистрации, ни сервера PassPony. Приложение подключается к сети только для работы с удалённым git-репозиторием, который вы настроите.
Ни аналитики, ни рекламы, ни отслеживания.
Открытый исходный код, Apache-2.0. Всё приложение и его ядро на Rust опубликованы в открытом git-репозитории, чтобы любой мог провести аудит.

ФОРМАТЫ
Хранилища passage шифруются современными идентификаторами age.
Хранилища pass шифруются ключами OpenPGP (Cv25519 и X25519/Ed25519 программно). Для хранилищ с ключами RSA нужна смарт-карта, которая пока не поддерживается.
У каждого формата своё хранилище; переключение никогда не затрагивает другое.

Доступно на английском, испанском, французском, немецком, упрощённом китайском, бразильском португальском и русском языках.

Если вы уже пользуетесь pass или passage, PassPony станет недостающей мобильной частью вашей системы. Если вы никогда ими не пользовались, приветственный тур при первом запуске поможет вам добавить первый пароль примерно за минуту.
